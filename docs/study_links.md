# 실험 링크

참가자 16명 분. 참가자를 앉히기 전에 아래 링크로 연다.

두 가지를 함께 균형 맞춘다:

- **도구 순서** — baseline 먼저 / SceneLens 먼저
- **대본 순서** — 대본 A 먼저 / 대본 B 먼저

한 사람은 **두 조건에 서로 다른 대본**을 쓴다 (같은 대본이면 두 번째 조건에서 이야기를 이미 알아 학습 효과가 생긴다). 네 조합을 4명씩 돌려 16명이 된다:

| 패턴 | 해당 참가자 | 1번째 | 2번째 |
| --- | --- | --- | --- |
| 1 | P01 P05 P09 P13 | baseline · 대본 A | SceneLens · 대본 B |
| 2 | P02 P06 P10 P14 | SceneLens · 대본 A | baseline · 대본 B |
| 3 | P03 P07 P11 P15 | baseline · 대본 B | SceneLens · 대본 A |
| 4 | P04 P08 P12 P16 | SceneLens · 대본 B | baseline · 대본 A |

이렇게 하면 baseline·SceneLens 각각 대본 A 8명·대본 B 8명, 각 도구가 1번째 8명·2번째 8명, 각 대본이 1번째 8명·2번째 8명으로 맞는다.

**대본은 링크에 넣지 않는다.** 조건을 시작하기 전에 실험자가 종이(또는 문서)로 해당 대본을 참가자에게 건넨다 — 아래 표의 `1번째`/`2번째` 열이 그 배정이다.

링크에 붙은 값이 하는 일:

- `participant` — 참가자 번호. **두 링크에 같은 번호**여야 같은 사람의 두 조건이 짝지어진다.
- `condition` — 어느 도구인가.
- `order` — 이 사람이 **몇 번째로** 한 조건인가. 순서 효과를 조건 차이와 가른다.

여는 것 말고 실험 중에 할 일은 두 번뿐이다 — 제작 직전 **`과제 시작`**, 20분 뒤 **`과제 종료 · 내보내기`**. 그다음 **`다음 참가자 · 조건 준비`**로 비우고 다음 링크로 넘어간다.

링크를 쓰지 않아도 된다. 기본 주소로 열고 **Ctrl+Shift+C**를 누르면 같은 세 값을 차례로 묻는다. 링크는 그 입력을 미리 해 두는 것일 뿐이다.

17명 이상이 필요하면 번호만 이어 붙이고 위 네 패턴을 순서대로 다시 돌린다 — `P17`은 패턴 1, `P18`은 패턴 2…
