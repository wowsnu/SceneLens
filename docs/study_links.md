# 실험 링크

참가자 20명 분. 참가자를 앉히기 전에 아래 링크로 연다. 순서는 **홀수 = baseline 먼저**, **짝수 = SceneLens 먼저**로 균형을 맞춘 것이다.

링크에 붙은 값이 하는 일:

- `participant` — 참가자 번호. **두 링크에 같은 번호**여야 같은 사람의 두 조건이 짝지어진다.
- `condition` — 어느 도구인가.
- `order` — 이 사람이 **몇 번째로** 한 조건인가. 순서 효과를 조건 차이와 가른다.

여는 것 말고 실험 중에 할 일은 두 번뿐이다 — 제작 직전 **`과제 시작`**, 20분 뒤 **`과제 종료 · 내보내기`**. 그다음 **`다음 참가자 · 조건 준비`**로 비우고 다음 링크로 넘어간다.

링크를 쓰지 않아도 된다. 기본 주소로 열고 **Ctrl+Shift+C**를 누르면 같은 세 값을 차례로 묻는다. 링크는 그 입력을 미리 해 두는 것일 뿐이다.

21명 이상이 필요하면 번호만 바꾼다 — `participant=P21`. 홀수는 baseline 먼저, 짝수는 SceneLens 먼저를 그대로 이어간다.
