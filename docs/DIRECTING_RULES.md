# 연출 분석 고정 규칙과 이론 연결

## 원칙

- 관점은 문제를 발견하는 근거이고, 층위는 문제를 수정할 위치다.
- 미장센·촬영·편집은 모두 `속성 / 컷 구성 / 컷 관계 / 씬 구조`를 사용할 수 있다.
- 개별 규칙이 네 층위에서 똑같이 자주 발동할 필요는 없다.
- 규칙은 기법 목록이 아니라 패널을 검토하는 최소 판단 기준이다.
- 진단은 실제 화면 근거가 있을 때만 생성하며, 의도적 차이는 질문으로 남긴다.

관점이 겹칠 때는 보이는 현상보다 원인으로 구분한다.

- 요소의 존재·배치·몸 방향이 원인: 미장센
- 프레이밍·초점·카메라 위치가 원인: 촬영
- 컷의 선택·순서·이음새가 원인: 편집

카메라 움직임은 패널 이미지에서 추측하지 않는다. 사용자가 남긴 화살표나 메모가
분석 입력에 있을 때만 진단한다. 화살표의 시작점→끝점은 피사체의 화면 이동이 아니라
카메라가 이동하거나 회전해 향하는 방향으로 해석한다.

정지 스토리보드에 컷 길이·진입점·종료점이 없으면 정확한 페이싱을 단정하지 않는다.
패널 배열에서 확인되는 시각적 반복과 변화만 진단하고, 시간 정보가 필요하면 질문한다.

## 분석 흐름

1. 관점별 고정 규칙 중 실제 패널에 해당하는 후보를 찾는다.
2. 후보 조건과 제외 조건을 함께 확인한다.
3. 선택한 `rule_id`에 연결된 이론만 참고한다.
4. 화면 근거가 있을 때만 진단하고 실제 원인의 층위를 선택한다.
5. 이론은 진단을 설명하는 근거로만 사용하며 문제를 만들어내는 근거로 쓰지 않는다.
