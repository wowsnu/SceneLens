# Baseline 스토리보드 사이트 인수인계

이 문서는 SceneLens와 별도로 만들 baseline 사이트의 구현 기준이다. 현재
SceneLens 앱에 baseline 모드를 추가하지 않는다. baseline은 별도 앱 또는
별도 배포 대상으로 만들고, 이음새·렌즈·관객 검토·AI 진단은 포함하지 않는다.

## 목적

SceneLens의 효과를 비교하기 위한 최소 스토리보드 편집기를 만든다. 사용자는
대본을 입력하고, 자동으로 나뉜 장면과 보강된 내용을 확인한 뒤 panels에서
기본적인 샷 편집만 한다.

## 핵심 흐름

```text
Script 입력
  → 자동 씬 분할
  → 씬별 내용 자동 보강
  → Panels에서 샷 편집
  → 저장/내보내기
```

대본을 `cut plan` 단계로 먼저 보내는 흐름은 baseline에 사용하지 않는다. 씬
분할 결과는 장면 단위로 바로 만들어야 하며, 빈 장면을 만들기보다 입력된
내용을 바탕으로 제목·장소·시간대·행동 요약을 자동으로 채운다.

## Panels 최소 기능

- 샷 사이 `+` 버튼: 해당 위치에 빈 샷을 즉시 삽입한다.
- 마지막 `+` 버튼: 마지막에 새 샷을 추가한다.
- 샷 삭제: 샷 카드에서 삭제하고, 최소 한 장은 남긴다.
- 샷 편집: 제목, 설명/대본, 이미지 또는 이미지 자리표시자를 수정한다.
- 샷 순서 변경: 드래그 앤 드롭 또는 위/아래 이동 버튼 중 하나를 제공한다.
- 삽입·삭제 후 샷 번호와 현재 선택 상태를 보정한다.
- 새로고침 후에도 현재 씬과 샷 데이터가 복원된다.

## 포함하지 않는 것

- 샷 사이의 이음새(seam)와 시간·행동·연결 방식
- SceneLens의 시간/인물/공간 상태 축
- 카메라·미장센·편집 렌즈 진단
- 관객 검토와 읽기 트랙
- AI gap fill, auto-fill, 생성 결과 비교

## 권장 데이터 형태

```js
{
  id: 'scene-1',
  title: '실험실의 밤',
  sourceText: '...',
  facts: { time: '밤', location: '물리학과 실험실' },
  shots: [
    {
      id: 'shot-1',
      title: '실험실 전경',
      description: '...',
      image: null,
    },
  ],
}
```

AI가 씬을 나눌 때는 `sourceText`를 보존하고, 사람이 수정한 `title`,
`description`, `image`는 다음 자동 생성 때 덮어쓰지 않는다.

## 완료 기준

1. 새 프로젝트에서 Script를 입력하면 하나 이상의 씬이 생성된다.
2. 씬을 선택하면 Panels가 해당 씬의 샷만 표시한다.
3. 샷 사이 `+`로 삽입한 샷이 정확한 위치에 나타난다.
4. 삭제 후 번호, 선택 상태, 저장 데이터가 일관된다.
5. baseline 화면 어디에도 seam 또는 SceneLens 전용 용어가 노출되지 않는다.

이 문서를 기준으로 baseline 담당자는 별도 브랜치/앱에서 작업한다. 현재
`main`의 SceneLens 구현과 컴포넌트를 직접 단순화하거나 되돌리지 않는다.
